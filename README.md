# Wifi Card Games（wifi-card-games）

多人联机**卡牌小游戏合集**模组（Minecraft **1.21.1** · Fabric · **服务端权威**），目前包含
**斗地主**（经典 / 花牌万能牌模式，标准 / 民间规则集）、**棋类游戏**
（**黑白棋** / **五子棋** / **围棋**，共用一套大厅与房间系统）与 **UNO**（最多 10 人）。

- 模组 ID：`wifi-card-games`　|　入口：`io.wifi.cards.CardGameMod`（伞形入口，为后续更多卡牌游戏预留）
- 斗地主子模块：`io.wifi.cards.doudizhu`　|　棋类子模块：`io.wifi.cards.board`（黑白棋/五子棋/围棋）　|　UNO 子模块：`io.wifi.cards.uno`

---

## ✨ 功能特性

### 房间与联机（纯内存，无持久化）
- **创建房间**：可选择 经典/花牌 模式、标准/民间 规则集、是否公布到聊天栏
- **一键加入**：公布到聊天栏的房间可直接点击「[点击加入]」；也可输入房间码加入
- **邀请**：`/doudizhu invite <玩家>` 发送可点击的邀请消息
- **满 3 人自动开局**；等待/结算中可随时离开

### 斗地主玩法
- **叫分**：不叫 / 1 / 2 / 3 分（须高于当前最高分）
- **抢地主**：有人叫 3 分触发，轮流抢/不抢，**连续 2 人不抢即终止**（底分 3）；无人叫 3 则最高分者当地主；全不叫重新发牌
- **出牌**：完整牌型识别与压制（单/对/三带一/三带二/顺子/连对/飞机带翅/四带二/炸弹/火箭，**无三王炸**），炸弹/火箭当场倍数 ×2
- **花牌模式**（万能牌）：55 张、底牌 4 张；花牌可代替任意牌，花牌+三张=含花牌炸弹；该模式**禁止三带二**
- **明牌**：地主在出第一手牌前可选择公开全部手牌，所有玩家可见（随出牌同步移除）
- **出牌时限 30 秒**：超时自动行动

### 托管与稳定性
- **托管**：打牌界面任意时刻开启/取消（叫分→不叫、抢→不抢、出牌→自动找最优）
- **断线自动托管**：对局中掉线由机器人代打，对局继续；**重连后完整状态同步**（手牌/底牌/倍数/倒计时/明牌/托管状态）
- **退出游戏**：对局中可主动退出（按钮）或由管理员强制踢出，座位转「机器人托管」继续对局；房间内无真人玩家则自动关闭房间

### 界面
- 文字化牌面：点击/滑动选牌（滑到未选中的牌自动选中，已选中的自动取消，快速滑动不漏牌）、提示、明牌按钮
- 游戏内聊天：按**聊天键**（原版按键，默认 T）打开聊天框，关闭/发送后自动回到牌局，聊天历史由原版 HUD 渲染
- 大厅 / 规则介绍（可滚动静音）/ 结算界面；无全局背景虚化，仅内容处有半透明黑底

## ♟️ 棋类游戏（黑白棋 / 五子棋 / 围棋）

三个棋类游戏**共用一套大厅、房间系统、网络协议与棋盘界面**（`/chess`），
棋盘渲染通过 `gui.pose().scale()` **自适应窗口大小**（大窗口放大、小窗口缩小，
永不溢出/遮挡按钮，小窗口下点击命中依然准确）。

### 房间与联机
- **统一大厅 `/chess`**：选游戏（围棋可选 9/19 路）→ 创建房间；或输入房间码加入
- **大厅房间列表**：实时展示所有房间——等待中的可点击**加入**，对局中的可点击**旁观**
- **旁观**：对局开始后可旁观（大厅列表 / 开局聊天栏公告 / `/chess spectate <房间码>`），
  实时观看完整棋盘与落子，人数不限，随时可退出
- **满 2 人自动开局**；公布到聊天栏的房间可点击加入；`/chess invite <玩家>` 邀请

### 玩法
- **黑白棋**（8×8）：黑先；无合法落点时自动停一手换边，双方均无落点则数子定胜负
- **五子棋**（15×15）：黑先；先五连者胜，棋盘下满平局；无禁手
- **围棋**（9 或 19 路）：黑先，落子于交叉点；**气/提子/禁自杀/简单劫**；双方连续停一手或
  **连续 4 手无人落子**按中国规则数子、**黑贴 3.75 子**定胜负
- 每步时限 **60 秒**：超时五子棋/黑白棋由 AI 托管走一步（评分表/贪心），围棋直接**跳过**轮到对方
- 游戏内可随时**认输**（围棋另有「停一手」按钮）
- **规则介绍**：大厅「规则介绍」按钮或棋盘界面左下角「规则」按钮（可滚动查看三棋完整规则）
- **游戏内聊天**：按**聊天键**（原版按键，默认 T）打开聊天框，关闭/发送后自动回到棋盘界面

### 托管与稳定性
- **五子棋/黑白棋**：退出/断线后座位转「机器人托管」（AI 代打），对局继续；重连后完整快照同步
- **围棋无托管**：一方退出/断线直接结束本局（对方获胜）；双方连续多轮未落子自动数子终局
- **全部玩家非真人或全部离线** → 自动结束本局并关闭房间
- 调试机器人：五子棋/黑白棋创建房间可选 1 个 AI 陪练（围棋不提供）

## 🎴 UNO（最多 10 人）

**标准 108 张**（四色 0~9 + 跳过/反转/+2，万能 ×4、万能+4 ×4），开局每人 7 张、
翻起牌须为数字牌。**房间最多 10 人**，由**房主（座位 0）点击「开始游戏」**开局
（至少 2 人，可创建房间时加入 0~9 个机器人补位）。

### 玩法
- **出牌**：与顶牌**同色或同点数**可打，万能牌任意可打（打出前弹 4 色选色）
- **功能牌**：跳过跳下家；反转转向（**2 人局视为跳过**）；+2 下家罚 2 张并跳过；
  万能+4 选色 + 下家罚 4 张并跳过（不做"无同色才可打"限制，休闲规则）
- **抽牌**：无牌可打时点「抽牌」（或点击牌堆）抽 1 张——抽到可打的牌可**打出或跳过**，
  抽到不可打的牌自动跳过；牌堆空时洗回弃牌堆（保留顶牌）
- **UNO 喊牌**：打出倒数第二张（剩 1 张）后须点「喊 UNO！」；未喊且被其他玩家点
  「抓 … UNO」抓住则**罚 2 张**（抓成功后窗口关闭）；**无人抓时轮到自己自动罚 2 张**
  （聊天栏 + 牌桌提示 + 语音"罚两张"）；窗口在下一次轮到自己时截止
- **先出完手牌者获胜**（单局制），结算界面可「再来一局」（房间不散直接重开）
- **出牌时限 30 秒**：超时自动抽牌（可打则打出）

### 托管与稳定性
- **托管**：打牌界面任意时刻开启/取消（自动找可打的牌、自动选色、自动喊 UNO）
- **断线自动托管**：对局中掉线由机器人代打，对局继续；**重连后完整状态同步**
  （手牌/当前颜色/方向/倒计时/UNO 状态/托管状态）
- **退出游戏**：对局中可主动退出（按钮），座位转「机器人托管」继续对局；房间内无真人玩家则自动关闭房间
- **旁观**：对局开始后可旁观（开局聊天栏公告 / `/uno spectate <房间码>`），左侧面板透视各家完整手牌
- 语音：喊 UNO 播"UNO"、被抓罚牌播"罚两张"（edge-tts 生成，源文本 `tools/input_uno.txt`，
  脚本 `tools/gen_sound.py`）；其余操作音效用 Minecraft 内置音效
- 界面：大厅（可开规则介绍）、牌桌左下角「规则 / 历史」（事件记录：出牌/抽牌/罚牌/喊 UNO，
  玩家名高亮，可滚动查看）、结算界面；牌桌内按**聊天键**（原版按键，默认 T）打开聊天框，
  关闭/发送后自动回到牌局

## 🚀 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)（Minecraft 1.21.1）
2. 下载本模组 jar 与 [Fabric API](https://modrinth.com/mod/fabric-api)，放入 `mods` 文件夹
3. 启动游戏（单人或多人服务器均可，服务端必须安装本模组与 Fabric API）

## 🎮 快速开始

**斗地主**：
1. 输入 `/doudizhu` 打开大厅
2. **创建房间**（选模式/规则集/是否公布）或输入房间码**加入**
3. 满 3 人自动开局（开发测试可用 `/doudizhu debug bots 2` 补假人）
4. 叫分 → 抢地主 → 出牌；可随时「托管」或「退出」

**棋类（黑白棋 / 五子棋 / 围棋）**：
1. 输入 `/chess` 打开棋类大厅
2. 选择游戏（围棋可选 9/19 路）→ **创建房间**，或输入房间码**加入**；大厅下方列表可旁观对局中的房间
3. 满 2 人自动开局（五子棋/黑白棋开发测试可用 `/chess debug bots 1` 补 AI 陪练）
4. 点击棋盘落子，可随时「认输」或「退出」；围棋另有「停一手」

**UNO**：
1. 输入 `/uno` 打开大厅
2. **创建房间**（可带 0~9 个机器人、是否公布）或输入房间码**加入**
3. **房主点击「开始游戏」**（至少 2 人）开局
4. 出牌/抽牌，剩 1 张记得「喊 UNO！」；先出完手牌者获胜，可「再来一局」

## 🃏 规则摘要

- **大小**：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王
- **牌型**：单牌 / 对子 / 三张 / 三带一 / 三带二（民间规则无）/ 顺子（≥5 张）/ 连对（≥3 对）/ 飞机（≥2 组，可带翅膀）/ 四带二 / 炸弹 / 火箭（大小王）
- **压制**：同型同张数比最大点；四带二不可互压；炸弹压一般牌型，火箭最大，炸弹互压比点
- **花牌模式**：花牌为万能牌，可代替任意一张牌参与组合；花牌+三张 = 含花牌炸弹；禁止三带二
- **结算**：底分 × 倍数（炸弹/火箭/含花牌炸弹当场 ×2）；地主胜 +2×底分×倍数、农民各 −底分×倍数，败则相反（仅本局展示，不存储）
- 完整规则见游戏内「规则介绍」界面

## 🔧 开发

```bash
# 构建
./gradlew build

# 单元测试（斗地主规则 26 + 自动出牌 12；棋类规则：黑白棋 8 / 五子棋 9 / 围棋 10；UNO 规则 9）
./gradlew test
```

- 入口：`io.wifi.cards.CardGameMod`（服务端）/ `io.wifi.cards.CardGameModClient`（客户端），
  分别载入 `doudizhu` 子模块（`DdzMod` / `DdzClient`）、`board` 棋类子模块（`BoardMod` / `BoardClient`）
  与 `uno` 子模块（`UnoMod` / `UnoClient`）
- 棋类子模块结构：`io.wifi.cards.board` 为共用框架（房间/协议/大厅/棋盘界面），
  `othello` / `gomoku` / `go` 子包为各自的纯 Java 规则引擎（可单测）与服务端状态机
- UNO 子模块结构：`io.wifi.cards.uno` 镜像斗地主——`card`（牌池 108 张）/ `game`（服务端状态机 +
  机器人 AI）/ `manager`（动态座位房间，最多 10 人）/ `network`（协议）/ `gui`（大厅/牌桌/结算）；
  UNO 房间为**动态座位列表**（斗地主为固定 3 座数组），开局由房主点「开始游戏」而非满员自动开
- 棋盘界面（`BoardGameScreen`）为三棋共用：棋盘经 `gui.pose().scale()` 随窗口自适应缩放，
  顶栏与按钮固定像素；鼠标点击按最近一帧的 scale/offset 逆变换命中
- **客户端/服务端严格分离**：服务端可达类不得引用任何 `net.minecraft.client.*` 包，保证服务端可独立启动（构建后已做字节码验证）
- 对局状态由服务端权威，客户端为纯渲染 + 操作转发；断线重连通过 `ReconnectS2C` 完整快照同步
